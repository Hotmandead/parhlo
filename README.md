# Parhlo

Screen-Aware macOS AI Companion with Live Visual Explanations.

A native macOS screen-aware AI assistant optimized for Apple Silicon (`arm64-apple-macosx`) that perceives on-screen content in real time, converses naturally via low-latency bidirectional voice using the Gemini Live API (`gemini-3.8-live`), and draws live, click-through animated visual explanations directly over macOS applications without stealing focus.
